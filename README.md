### 👨‍💻 Kısaca

7+ yıllık yazılım geliştirme deneyimimle fintech (faktoring) sistemlerinde çalışıyorum: ödeme entegrasyonları, veri taşıma ve migration süreçleri (MSSQL → Oracle), tahsilat otomasyonları ve yasal servis entegrasyonları (MERSİS, GİB, Risk Merkezi). Mimari kararlar almayı, performans optimizasyonunu ve ekipte bilgi paylaşımını önemsiyorum.

Kendi ürünüm **Organizasyon.co**'yu ise fikirden üretime kadar uçtan uca kendim geliştiriyorum.

### 🚀 Organizasyon.co — Kendi ürünüm

Müşterilerin etkinlik talebi bıraktığı, firmaların teklif verdiği ve tarafların uçtan uca güvenli biçimde anlaştığı platform + **ArtiCall** AI destekli çağrı merkezi altyapısı:

- 🖥️ **Arayüz:** Next.js · React · TypeScript · Tailwind CSS
- ⚙️ **Backend:** Python · FastAPI · PostgreSQL/PostGIS · Redis
- ☎️ **İletişim katmanı:** Kamailio · Asterisk · SIP/VoIP · WebRTC
- 📦 **Altyapı:** Docker · Linux · Nginx · Cloudflare · GitHub Actions
- 📱 **Mobil:** Flutter · Dart · iOS

> 🧩 **İlgi alanlarım:** pazaryeri entegrasyonları (Trendyol · Hepsiburada), SIP/VoIP altyapıları, AI destekli otomasyonlar
